# WinRAR keygen

Генератор регистрационного ключа `rarreg.key` для **оригинального (непатченого)**
WinRAR x64. Схема восстановлена исключительно из реверса `winrar.exe` 7.13
(IDA + x64dbg); кейген сам извлекает константы из установленного `winrar.exe`
**по data flow — без адресов и без хардкода значений**.

## Файлы

| файл | что это |
|---|---|
| `keygen.c` | точка входа и последовательность этапов |
| `app/` | консольный ввод, формат ключа, запись файла, получение системной случайности |
| `pe/` | чтение PE, SIMD-сканер RIP-relative ссылок, извлечение констант |
| `crypto/` | отдельные примитивы: SHA-1, CRC-32, GF(2^15), поле расширения, кривая, длинная арифметика, ChaCha20, деривация и подпись |
| `build.cmd` | сборка C99 через Clang и LLD, без Visual Studio |

## Как извлекаются константы

1. Парсится PE (ImageBase + секции) для маппинга VA ↔ файловое смещение.
2. Сканируется код на **RIP-relative ссылки всех кодировок**:
   LEA/MOV (±REX), SSE (`0F 10/11/28/29/6F/7F`), VEX2/VEX3, EVEX.
3. Среди данных, на которые ссылается код:
   - **G** — пара структур `[u32 17][17×u16 < 0x8000]`, для которой
     `b = y² + xy + x³` — малый элемент поля (b = 0xA1 выводится, не зашит);
   - **n** — структура `[u32 16][16×u16]`, для которой `n·G = ∞` (порядок точки).

Единственная константа в коде — мастер-сид скаляра `d`
(в бинарнике его нет; `d` согласован с вшитым публичным ключом `Q`).

## Что вскрыто в бинарнике

| Компонент | Где |
|---|---|
| Проверка ключа | `sub_1400C8644` (7.13) |
| Анти-тампер | `~crc32(Q) == 0x26E7CFB8` |
| Хеш-инт e | SHA-1(msg) ‖ 10-байтовый трейлер |
| Подпись | `r = (x(kG) + e) mod n`, `s = (k − d·r) mod n` (`sub_1400D148C`) |
| Верификация | `e == r − x(sG + rQ) mod n` (`sub_1400D15E4`) |
| Кривая | `y² + xy = x³ + b`, b = 0xA1, над GF((2^15)^17) |
| Поле | GF(2^15): x¹⁵+x+1 (0x8003); башня: t¹⁷+t³+1 |
| Деривация | `limb[i] = low16(SHA1(LE32(i) ‖ SHA1(seed)))` |

Формат ключа: сегменты длин 64/122/122/50 + префикс «6412212250» + чексумма
`~crc32(license‖name‖items)`, строки по 54 символа.

## Сборка

```
build.cmd
```

Результат — `keygen.exe`. Используется отдельный [LLVM toolchain](https://github.com/mstorsjo/llvm-mingw/releases/tag/20261006):
Clang, LLD, compiler-rt и LLVM libunwind, с собственными Windows-заголовками и библиотеками.
Архив `llvm-mingw-20261006-msvcrt-x86_64.zip` распаковывается в
`%LOCALAPPDATA%\Programs\llvm-mingw`; другой каталог задаётся через `LLVM_MINGW`.
Сборка не использует GCC, libgcc, MSYS2 или окружение Visual Studio.

Цель сборки — базовый x64/SSE2. SSE2 используется для фильтрации RIP-relative
ссылок и XOR элементов поля. CRC остаётся IEEE CRC-32 (`0xEDB88320`);
инструкция процессора `CRC32` вычисляет CRC-32C с другим полиномом.

Случайные числа для подписей генерирует ChaCha20. Ключ и nonce заполняются через
`BCryptGenRandom`; при ошибке генерация прекращается. Для сборки используется
системная библиотека `bcrypt` (Windows Vista SP2 и новее).

## Использование

Запуск без аргументов, в том числе двойным кликом, открывает консольный диалог
для имени и типа лицензии. После завершения программа ждёт Enter.
Если WinRAR не найден или файл не подходит, запрашивается путь к `WinRAR.exe`;
путь можно вставить в кавычках, пустая строка отменяет операцию.

```
keygen.exe "Имя" "Тип лицензии"                       → берёт C:\Program Files\WinRAR\WinRAR.exe
keygen.exe "Имя" "Тип лицензии" "C:\...\WinRAR.exe"  → любую версию/копию
```

Тип лицензии — любой текст (например `Single PC usage license`); он подписывается
и показывается в «Справка → О программе».

При текущей проверке совпали RIP-relative ссылки и константы девяти локальных
версий WinRAR; подтверждены подписи, цепочка публичных ключей, UID и CRC.
ChaCha20 проверен по вектору RFC 8439, включая чтение частями и исчерпание счётчика.

## Проверено на реальных версиях (живой тест)

Все версии скачаны с rarlab (официальные инсталляторы), `WinRAR.exe` извлечён,
кейген сгенерировал ключ **под константы этой же версии**, затем:
* крипто-верификация ключа (подписи против вшитого Q + цепочка pubkey/UID);
* живой запуск: без ключа заголовок окна содержит `(evaluation copy)`, с ключом — нет.

| 6.00 | OK | 4/4 | `WinRAR-Архив (evaluation copy)` | `WinRAR-Архив` |
| 6.24 | OK | 4/4 | `WinRAR-Архив (evaluation copy)` | `WinRAR-Архив` |

Дополнительно:
* 7.13 под отладчиком: флаг регистрации `byte_140268600 = 1`, имя из ключа записано;

* кодировки загрузки констант отличаются по версиям (SSE `movaps` в 5.9x–6.x/7.12,
  AVX-512 EVEX в 7.13) — сканер ловит все.

## Где лежит лицензия (для теста удалить)

Кейген пишет: `%APPDATA%\WinRAR\rarreg.key`

```
Remove-Item "$env:APPDATA\WinRAR\rarreg.key*" -Force   # удалить ключ (+ бэкапы)
```

WinRAR читает ключ также из папки установки (`C:\Program Files\WinRAR\rarreg.key`).
Проверка выполняется при старте — после удаления перезапустить WinRAR.
